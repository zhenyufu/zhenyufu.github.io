How to install Debian Guest Additions in VM VirtualBox

Wed 29 July 2015 · Linux · Debian, Linux, VirtualBox

Install Guest Additions for Debian to enable full screen display and more.

Software

  • VM VirtualBox 4.3.30
  • Debian 8.1.0 amd64

Reading

  • Guest Additions

1. Install dkms

apt-get install dkms

2. Insert Guest Additions CD image

3. cd to location of the CD image in /media

run:

sh ./VBoxLinuxAdditions.run

If the above fails, check you have the following packages installed: * make * gcc * linux-headers (run "uname -a" to check kernel version)
