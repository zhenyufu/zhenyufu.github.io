What Debian standard system utilities include

Tue 28 July 2015 · Linux · Debian, Linux, Commands

When installing Debian 8, there is a software selection page where "standard system utilities" is preselected for you. Ever wondered what that package includes? Use tasksel to find out.

Software

  • Debian 8.1.0 amd64

Reading

  • tasksel

In Debian terminal, run

tasksel --task-packages standard

This command seems to only work if "standard system utilities" was not installed during Debian installation. It will list what is included in "standard system utilities":
