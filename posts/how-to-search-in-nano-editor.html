How to search in nano editor

Tue 28 July 2015 · Linux · GNU, Nano

nano's search uses Ctrl + w which acts like Ctrl + f in other common editors

Software

  • GNU nano version 2.2.6

Reading

  • Nano/Basics Guide

Search

  • Search a string:
Ctrl + w

  • Search the next string:
Alt + w
